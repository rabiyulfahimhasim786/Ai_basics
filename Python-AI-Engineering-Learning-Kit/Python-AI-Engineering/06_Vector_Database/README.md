# 06 – Vector database with Qdrant Cloud

**Goal:** Learn embeddings, vector dimensions, collection creation, upsert and similarity search without adding an LLM answer-generation step. This separates vector search from RAG.

Set `OPENAI_API_KEY`, `QDRANT_URL`, and `QDRANT_API_KEY`, then run `python main.py`. OpenRouter is not used in this lesson because OpenRouter does not provide an embeddings endpoint; the chat/LLM lessons support it.
