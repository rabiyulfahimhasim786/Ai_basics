# 04 – LangChain basics

**Goal:** Connect a prompt template to a chat model using a runnable chain. This lesson is a chain, not an autonomous agent.

Install `langchain`, `langchain-openai`, and `python-dotenv`; set `OPENAI_API_KEY`. To use OpenRouter instead, set `LLM_PROVIDER=openrouter`, `OPENROUTER_API_KEY`, and `OPENROUTER_MODEL` (for example `nvidia/nemotron-3-ultra-550b-a55b:free`). See `.env.example`.
Run `python main.py`.
